# 💱 Taka EX — Currency Converter

A simple and interactive **Currency Converter Web Application** built with **HTML, CSS, and JavaScript**.

The project allows users to enter an amount, select a source currency and target currency, and calculate the corresponding exchange value through an easy-to-use web interface.

---

## 🚀 Project Overview

**Taka EX** is a frontend currency-conversion project created to practice web development, JavaScript logic, user interaction, and API-based exchange-rate concepts.

The application provides a clean interface where users can:

- 💵 Enter an amount
- 🌍 Select a source currency
- 💱 Select a target currency
- 🔄 Switch between currencies
- 📊 View the exchange rate
- 🧮 Calculate converted values
- 🇺🇸 🇪🇺 🇬🇧 🇧🇩 Work with common currencies

The current interface includes **USD, EUR, GBP, and BDT** as selectable currencies. :contentReference[oaicite:1]{index=1}
